# Assessment coverage

| Brief requirement | Implementation / remaining evidence |
|---|---|
| Digit 6 domain, specific problem | Low-light frame enhancement and target-region inspection |
| 30 images; 10 student captures | Folder structure and manifest provided; student must collect images |
| Single and folder acquisition | Single/multiple uploader, ZIP folder, CLI recursive folder input |
| Validation and metadata | decode_image and Workspace metadata |
| At least two colour spaces | Lab luminance, grayscale and binary masks |
| Contrast and illumination correction | CLAHE, gamma, smooth-field division |
| At least two noise filters | Gaussian, median, bilateral comparison |
| ROI and transformation | Percentage crop, rotation, plate rectification |
| Four meaningful domain techniques | Edges/contours, Otsu, morphology, connected components, shape features, counting, image differences |
| Domain outputs | People count, plate candidates and crops, changed regions, edge maps |
| Interface, controls, previews, reset, export | Streamlit browser tabs and sidebar |
| Processed images and CSV | Per-image or batch ZIP and summary CSV |
| At least 10 unseen tests, two measures | Evaluation tools provided; student must label/run unseen dataset |
| Technical report | Outline provided; actual data, screenshots and discussion required |
| 3–5 minute backup video and viva | Demo/viva guide; student must record and prepare |

No requirement is considered empirically satisfied merely because a control or placeholder exists. Dataset, accuracy evidence, completed report and recorded demo remain student work.
