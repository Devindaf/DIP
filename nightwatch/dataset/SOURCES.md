# Dataset provenance

`synthetic/night_plate.png`, `synthetic/blank.png`, `synthetic/change.png` are artificial fixtures generated by scripts/make_demo.py. They are explicitly excluded from real-world evaluation and are not claimed to be captured by the student.

If included, `development/opencv_basketball1.png` is the unmodified OpenCV sample from https://raw.githubusercontent.com/opencv/opencv/4.11.0/samples/data/basketball1.png. OpenCV 4.11 is distributed under Apache License 2.0; upstream license: https://github.com/opencv/opencv/blob/4.11.0/LICENSE. It is used only as a development smoke test for the bundled HOG detector. It is not an unseen benchmark or student-captured image.

Record your own image sources, permissions, resolution, format and intended test purpose in manifest.csv. Do not relabel synthetic or external images as student-captured. Do not report regression fixture results as real-world detection performance.
